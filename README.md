# Wildcard · for KIMI Talk（kimi-talk-signup-local）

Kimi Work 插件：在对话里浏览 Kimi Talk 及 Kimi 官方社区线下活动并完成报名。深度/付费用户可授权读取本人 Kimi 订阅信息进行快速核验，达标走 Wildcard 免审直通通道；其余用户正常排队审核。

Wildcard 是通用的活动报名分层工具，本仓库为 KIMI 社区版本。

## 安装

方式一（推荐）：在 Kimi 桌面版插件页「个人」页签，通过本地插件入口安装本仓库。

方式二（命令行）：

```bash
kimi-daimon kimi-plugin install https://github.com/jasonlovegugu/kimi-talk-signup-local --share-dir "<你的 daimon-share 目录>"
```

macOS 下 share 目录通常是 `~/Library/Application Support/kimi-desktop/daimon-share`。

## 使用

安装后直接用自然语言，例如：

- 最近有哪些 Kimi Talk 线下活动？
- 我想报名上海站的 Kimi Talk
- 我是深度用户，帮我走免审直通通道报名
